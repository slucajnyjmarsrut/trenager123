# JARVIS — ИИ-ассистент для Windows

Electron-приложение: чат с Claude, озвучка ответов, голосовой ввод, открытие сайтов/вкладок,
поиск, запуск программ и папок. Собирается в установщик `.exe` (NSIS).

## Сборка установщика (на Windows)

1. Установите Node.js 20+ (https://nodejs.org).
2. В папке проекта:
   ```
   npm install
   npm start        # запуск для проверки
   npm run dist     # сборка установщика в папку dist/
   ```
3. Готовый файл: `dist/JARVIS Setup 2.0.0.exe`.

## Первый запуск

Нажмите ⚙ и вставьте API-ключ Anthropic (console.anthropic.com). Ключ шифруется средствами Windows (DPAPI)
и хранится только на вашем компьютере. Модель по умолчанию: `claude-sonnet-5-5`
(можно поменять в `config.json` в папке `%APPDATA%\jarvis-assistant`, поле `model`).

## Что умеет

| Команда | Что происходит |
|---|---|
| «Открой YouTube» | `open_url` — вкладка в браузере по умолчанию |
| «Открой почту, ютуб и новости» | `open_tabs` — несколько вкладок (больше 3 — с подтверждением) |
| «Найди рецепт борща» | `web_search` — Google / Яндекс / DuckDuckGo / YouTube / Карты |
| «Запусти блокнот» | `launch_app` — встроенные программы |
| «Открой загрузки» | `open_folder` |
| «Сколько у меня памяти?» | `get_system_info` |

Свои программы: кнопка ＋, имя, выбор `.exe`. Запуск добавленных программ всегда требует подтверждения.

## Безопасность

- Открываются только `http/https` ссылки.
- Запуск программ — белый список + то, что вы добавили сами.
- `contextIsolation`, `sandbox` и строгий CSP включены, Node в интерфейсе недоступен.
- Приложение живёт в трее, Ctrl+Alt+J — показать/скрыть.

## Ограничения

- Голосовой ввод использует Web Speech API; в Electron он может не работать без доступа к службе Google.
  В этом случае пишите текстом, остальное работает.
- Иконка в трее — заглушка 1×1; положите свой `icon.ico` и укажите в `main.js`/`package.json`.
